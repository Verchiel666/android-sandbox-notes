noir-phone 追踪域名黑名单

生成于 2026-11-08 · HONOR BKQ-AN20 / Android 17 · 共 204 条可拦 + 17 条谨慎

一台手机上的 374 个安装包，逐个 APK 解 classes*.dex 与 resources.arsc，抽出 URL 与裸域名， 再按 Verlintas/NOIR 的规则（域名 label 分类）判断哪些是遥测/广告/崩溃上报。

订阅地址

https://verchiel666.github.io/android-sandbox-notes/blocklist/noir-trackers.txt      # AdGuard / AdGuard Home
https://verchiel666.github.io/android-sandbox-notes/blocklist/noir-trackers.hosts     # hosts
https://verchiel666.github.io/android-sandbox-notes/blocklist/noir-trackers-dnsmasq.conf  # OpenWrt dnsmasq
https://verchiel666.github.io/android-sandbox-notes/blocklist/noir-caution.txt        # 谨慎档（默认不拦）
https://verchiel666.github.io/android-sandbox-notes/blocklist/noir-blocklist.json     # 机器可读

怎么用

  • AdGuard / AdGuard Home：过滤器 → 自定义规则 → 粘贴 noir-trackers.txt 全文；或加订阅 URL。
  • OpenWrt：noir-trackers-dnsmasq.conf 丢进 /etc/dnsmasq.d/ 后重启 dnsmasq。
  • hosts：合并进系统的 hosts 文件。

口径（不吹不黑）

  • 这是静态证据：APK 里存在这个域名字符串 → 该域名被判为遥测类。不代表特定传输真的发生过。
  • 拦了可能有个别 App 功能异常（某些"统计"域名实际承载配置下发），出问题从 noir-caution.txt 反查、逐条放行。
  • 支付/登录/推送/验证码（如 static.geetest.com）已经划进谨慎档，默认不拦。
  • 清单随每日审计自动重生成，更新方式是重新发布这个页面。
